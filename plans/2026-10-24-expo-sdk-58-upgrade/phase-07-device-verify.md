# Phase 07 — Проверка на устройствах

Status: in_progress
Model tier: BALANCED — разбор рантайм-регрессий
Required rules: `ai/rules/common/deployment.md`, `ai/rules/projects/fin-app-mobile/architecture.md`

## Goal

Приложение на SDK 58 работает в Expo Go на Android-эмуляторе и на физическом iPhone.

## Implementation notes

- Android проверяет агент на эмуляторе `finapp_pixel7` через `rtk yarn android:emulator`.
- iPhone проверяет пользователь: Metro без `--localhost`, Expo Go 58 из App Store.
- Регрессии, найденные здесь, чинятся в этой фазе с повтором гейтов Phase 03.
- Пуш в `main` и `eas update` вне фазы — публикация после проверки остаётся решением пользователя через `deploy-preflight`.

## Scope

- Только исправления регрессий в `src/**`, найденных при проверке

## Checklist

- [ ] Android: все табы, графики, пикер даты, модалки, создание и редактирование транзакции, клавиатура на формах
- [ ] Android: тёмная и светлая системная тема, статус-бар, отступы edge-to-edge
- [ ] iPhone: запуск в Expo Go 58 без ошибки несовместимости, основные экраны
- [ ] Logcat / Metro без ошибок ворклетов и NativeWind

## Verification commands

- `rtk yarn android:emulator`
- `rtk npx expo start`

## Acceptance criteria

- На обеих платформах нет красного экрана и падений
- Вёрстка совпадает с SDK 57
- Подтверждение пользователя по iPhone записано в evidence
