# Фильтр «Превышен бюджет» на экране расходов — Implementation Plan

Дата: 19.10.2026

## Goal

- На экране расходов чип «Превышен бюджет» оставляет в списке только категории или подкатегории, превысившие бюджет текущего месяца
- Фильтр работает в обоих режимах и сочетается с переключателем «Категории / Подкатегории»

## Task Profile

`feature` — 2 feature-сигнала против 0 bugfix-сигналов.

Feature-сигналы:
1. Новое поведение экрана: фильтр, счётчик, плашка превышения, пустое состояние
2. Изменения в нескольких слоях — `features/categorySpending`, `shared/constants`, `tailwind.config.js`

Bugfix-сигналы: нет. Контракт API не меняется.

## Decisions Taken

- Эталон визуала — `designs/screens/category-spending.html` (чип, плашка, пустое состояние)
- Целевая версия — `1.13.0`
- План одобрен 19.10.2026; все фазы выполняются подряд без промежуточных остановок, пользователь проверяет результат один раз в конце

## Assumptions

- Фильтр — локальное состояние экрана, не сохраняется между запусками; по умолчанию выключен
- Элементы без бюджета, «Без категории» и остатки `rest:` никогда не считаются превышенными
- Фильтр применяется к верхнему уровню списка; раскрытая категория показывает все подкатегории
- Карточка «Бюджет на месяц» не фильтруется
- Новые компоненты используют цветовые токены `spending.*` в `tailwind.config.js`; существующие компоненты на токены не переводятся
- Изменения только в JS — доставка OTA, `runtimeVersion` не меняется
- Ветка для `1.13.0` — `r-1.13.0`; её создаёт пользователь (сейчас `r-1.12.0`)
