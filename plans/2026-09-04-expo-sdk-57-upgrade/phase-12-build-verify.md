# Phase 12 — Сборка и проверка на устройствах

Status: in_progress
Model tier: BALANCED
Required rules: `ai/rules/common/deployment.md`

## Goal

Апгрейд подтверждён на реальных устройствах, последствия смены `runtimeVersion` осознаны и зафиксированы.

## Implementation notes

Нативная сборка под iOS без платного Apple Developer Program недоступна — проверка iPhone идёт через Expo Go SDK 57.

По результату Phase 01 нативных билдов проекта не существует вовсе, установленных сборок нет. Поэтому смена `runtimeVersion` никого не затрагивает, а Android-билд остаётся необязательной проверкой: он подтверждает, что проект на SDK 57 вообще собирается нативно, но ни одному пользователю сейчас не адресован.

## Evidence note

Проверка выполнена на эмуляторе `finapp_pixel7` в Expo Go 57.0.9, на коде после всех правок Phase 08 и апгрейда axios до 1.20.0.

Инфраструктурная помеха и её причина: adb завис посреди Phase 08. Разбор показал около сотни осиротевших процессов `adb`, накопившихся от вызовов клиента за сессию — они забили сервер, и любая команда вставала намертво. Эмулятор при этом был жив. Лечение: снять все процессы `adb`, поднять сервер заново; устройство подхватилось без перезагрузки эмулятора. Отдельно пришлось освобождать порт 8081 от осиротевшего Metro.

Проверено на устройстве:
- Дашборд: суммы, сравнение месяцев, график, список кошельков с балансами в трёх валютах. Данные приходят через axios 1.20.0 — апгрейд Phase 09 подтверждён в рантайме
- Статус-бар светлый и читаемый — правка Phase 06 в силе
- Категории: все иконки рендерятся через новый `<Icon>` и совпадают со снимком до рефакторинга — сердце, книга, кошелёк, дом, портфель, подарок, wifi, ноты, футболка, машина, телефон
- Редактирование категории: форма засеяна данными загруженной категории (название, приоритет, цвет, иконка), превью иконки на месте. Это прямая проверка переписанной синхронизации состояния в `useCategoryEditScreen`
- Операции: список, фильтры, группировка по датам, иконки `TxItem` через новый `<Icon>`, суммы и валюты
- Редактирование транзакции: форма засеяна полностью — тип, сумма, кошелёк, категория, подкатегория, описание, дата. Прямая проверка переписанного `useEditTransactionForm`. Иконки `FormRow` рендерятся
- Пикер даты открылся на дате самой транзакции, 3 сентября, а не на текущей — переписанный сброс при открытии в `DateTimePickerModal` работает; заодно подтверждён `datetimepicker@9.1.0` после его метаний 9.1.0 → 8.6.0 → 9.1.0 по ступеням
- Edge-to-edge на экране редактирования: шапка стоит ниже статус-бара. Первый снимок показал наложение, но это оказался кадр посреди анимации открытия — повторный снимок чистый

Не проверено:
- Анимация вращения иконки обновления кошелька в `WalletRow`. Сам компонент рендерится корректно, но поймать вращение скриншотом не удалось. Правка там того же класса, что в `ErrorBanner`: `useState(() => new Animated.Value(0))` вместо `useRef(...).current`
- `ErrorBanner` — показывается только при ошибке сохранения, искусственно ломать сохранение не стал
- Поведение клавиатуры на формах — долг ещё с Phase 06
- Android-билд профиля `production`. Пункт помечен опциональным после Phase 01: нативных сборок проекта не существует, ни один пользователь такой билд не ждёт, а `eas config` уже подтвердил, что профиль валиден и резолвит SDK 57. Запускать платную сборку без адресата не стал

Дымовой прогон на физическом iPhone в Expo Go SDK 57 — исходная цель апгрейда — остаётся за пользователем. Важно: Metro сейчас поднят скриптом эмулятора в режиме `--localhost`, до телефона по сети он недоступен. Для проверки на iPhone нужен запуск в LAN-режиме, то есть `npx expo start` без `--localhost`.

- Причина зависаний adb найдена и устранена: осиротевшие клиентские процессы забивают сервер
- Не проверены: анимации `WalletRow` и `ErrorBanner`, клавиатура на формах
- Android production build пропущен осознанно — адресата у сборки нет
- Проверка на iPhone за пользователем; для неё Metro нужно поднять без `--localhost`
