# Phase 09 — Поведенческая приёмка в обоих клиентах

- Status: done
- Model tier: BALANCED
- Required rules: `ai/rules/common/agent-workflow.md`, `ai/rules/common/git-policy.md`, `ai/rules/common/implementation-plans.md`
- Prerequisites: Phase 08; оба клиента доступны, проект trusted в Codex

## Goal

Подтверждено, что одинаковый вход в свежих сессиях Claude Code и Codex даёт одинаковые этапы, ограничения, артефакты и условия остановки.

## Implementation Notes

- Каждый сценарий — отдельная свежая сессия каждого клиента на одинаковом исходном состоянии
- Изменяющие пробы — во временной копии проекта или на fixture-плане в scratch; EAS и git-мутации реально не запускаются
- Запись на каждый запуск: вход, клиент и версия, выбранные навык/роль, прочитанный канон, ожидание, факт, доказательство
- Непроверенный клиент или возможность — статус «не проверено», не «паритет подтверждён»
- Сценарии, которые требуют Codex, выполняет пользователь, если у исполнителя нет доступа к клиенту
