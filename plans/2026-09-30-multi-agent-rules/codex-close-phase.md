## 1. Одобрить хуки проекта (однократно)

Без сохранённого доверия проектные хуки пропускаются молча — проверено 30.09.2026.

1. Открыть в VS Code папку `C:\Projects\FinApp\fin-app-mobile`
2. Новый чат Codex, режим Agent. Запрос: «Создай файл tmp-hook-probe.txt в корне со словом probe через инструмент правки файлов. Больше ничего не трогай. Затем процитируй дословно любой дополнительный контекст, полученный после правки.»
3. Если расширение показывает запрос на доверие хукам проекта (`.codex/hooks.json`) — одобрить
4. Если запроса нет, а в ответе «none»: открыть терминал VS Code в корне проекта и запустить встроенный CLI интерактивно — `& "$env:USERPROFILE\.vscode\extensions\openai.chatgpt-26.917.62051-win32-x64\bin\windows-x86_64\codex.exe"`; в TUI выполнить ту же просьбу и одобрить хуки, когда CLI спросит; выйти. Доверие сохраняется в `~/.codex/config.toml`, раздел `[hooks.state]`
5. Повторить пункт 2 в новом чате расширения
6. Ожидаемо: агент цитирует `[post-edit] Files changed. Before reporting the work as done, run the sequence from ai/rules/common/post-code-workflow.md …`; после завершения хода — предупреждение `[session-end] …`, без ошибки хука и без самопродолжения
7. Удалить `tmp-hook-probe.txt`
8. Записать: был ли запрос доверия, где (расширение или CLI), дословное напоминание → `phase-06-codex-config.md`, Evidence Note, подраздел «Ручная проверка»
