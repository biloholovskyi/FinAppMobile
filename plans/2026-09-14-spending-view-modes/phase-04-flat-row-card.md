# Phase 04 — Карточка плоской строки и интеграция в список

- Status: done
- Model tier: BALANCED (`sonnet`)
- Required rules: `ai/rules/common/react.md`, `ai/rules/projects/fin-app-mobile/architecture.md`, `ai/rules/common/performance/_index.md`

## Goal

Плоский режим отрисован карточками строк в общем `FlatList` экрана и совпадает с прототипом.

## Implementation Notes

- `SpendingRowCard` пишется с нуля; от `CategoryCard` он отличается отсутствием раскрытия, шеврона и счётчика подкатегорий
- Карточка не оборачивается в `TouchableOpacity` — строка плоского списка некликабельна
- `renderItem` разбирает `kind` исчерпывающим сужением со стражем `never`
- Эталон визуала — блок `.flat-item` в `designs/screens/category-spending.html`

## Scope

Target state:

- `src/features/categorySpending/CategorySpendingScreen/SpendingRowCard.tsx` — карточка строки плоского списка: иконка и цвет родителя, название, подпись с именем родительской категории, сумма, процент-бейдж, `BudgetProgress`, мета-строка бюджета либо курсивная пометка об отсутствии бюджета
- `src/features/categorySpending/CategorySpendingScreen/CategorySpendingScreen.tsx` — `FlatList<SpendingListItem>`, `ViewModeSegment` в `ListHeaderComponent` между `BudgetSummaryCard` и подписью секции, `keyExtractor` по схеме составных ключей, `renderItem` с разбором `kind`

## Checklist

- [x] `SpendingRowCard` укладывается в `COMPONENT_MAX_LINES`, вложенность JSX не превышает 4
- [x] Подпись родительской категории показывается только при непустом `parentName`
- [x] Сумма и процент-бейдж окрашиваются в красный при превышении бюджета
- [x] Строка «Без категории» получает приглушённое оформление бейджа и текста
- [x] Отсутствие бюджета даёт пустой трек и курсивную пометку, полоса заливки не рисуется
- [x] Превышение рисует заливку на всю ширину и полосу превышения поверх
- [x] `keyExtractor` возвращает `row.id` для `flat` и составной ключ для `category`; индекс массива ключом не используется
- [x] `renderItem` разбирает `kind` исчерпывающе, недостижимая ветка закрыта стражем `never`
- [x] `renderItem` стабилизирован `useCallback`
- [x] Пустое состояние и состояния загрузки и ошибки работают в обоих режимах
- [x] Разметка использует `className`; `style` остаётся только для вычисляемых ширин и цветов
- [x] `SpendingRowCard` не импортирует `expo-router`

## Verification Commands

- `rtk yarn lint`
- `rtk yarn tsc --noEmit`
- `rtk npx expo start` — визуальная сверка обоих режимов с прототипом

## Acceptance Criteria

- Оба гейта проходят без ошибок
- В режиме «Подкатегории» категории с подкатегориями отдельными строками не показаны
- Сумма строк плоского списка совпадает со значением «Потрачено» в `BudgetSummaryCard`
- Порядок строк — по убыванию доли затрат
- Переключение режимов не даёт предупреждений о дублирующихся ключах в консоли Metro

## Evidence Note

Выполнено 14.09.2026.

- `SpendingRowCard.tsx` (93 строки, вложенность JSX 4) рендерит строку плоского списка: иконка и цвет родителя, имя, подпись родительской категории, сумма, бейдж доли, полоса бюджета, мета-строка либо курсивная пометка об отсутствии бюджета
- `PercentBadge.tsx` выделен и подключён в обеих карточках; `CategoryCard.tsx` сократился до 123 строк
- `renderSpendingItem` разбирает `kind` исчерпывающим `switch` со стражем `never` и подключает `SpendingRowCard` для ветки `flat`
- Строка `Без категории` опознаётся сравнением с `buildCategoryRowId(null)` и получает приглушённый цвет имени, суммы и бейджа
- `keyExtractor` работает через `getSpendingListItemKey`, индекс массива ключом не используется
- Гейты: `rtk yarn lint` — 0 ошибок, `rtk yarn tsc --noEmit` — без ошибок
- Отклонение от плана: `renderItem` объявлен функцией уровня модуля вместо `useCallback` — стабильная ссылка без зависимости от рендера компонента
- Отклонение от плана: сверх скоупа выделен `PercentBadge.tsx`, иначе вложенность JSX в карточке доходила до 5 при лимите 4
- Не выполнено в этой фазе: визуальная сверка с прототипом через `rtk npx expo start` — запуск дев-сервера за пользователем
