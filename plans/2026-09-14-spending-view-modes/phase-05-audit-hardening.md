# Phase 05 — Post-code, аудит и харденинг

- Status: done
- Model tier: DEEP (`opus`)
- Required rules: `ai/rules/common/post-code-workflow.md`, `ai/rules/common/skills/refactor-security-audit.md`, `ai/rules/common/patterns.md`

## Goal

Изменения экрана проходят полный аудит качества и безопасности, найденные дефекты исправлены, гейты перепрогнаны.

## Implementation Notes

- Аудит идёт по чек-листу `ai/rules/common/skills/refactor-security-audit.md`, ограниченному файлами фаз 01–04
- Находки группируются по severity: CRITICAL, HIGH, MEDIUM, LOW
- После исправлений гейты запускаются повторно — частичного прогона недостаточно
- Нарушения лимитов, оставленные за скоупом задачи, фиксируются как техдолг в отчёте, а не исправляются молча

## Scope

Target state: файлы, затронутые фазами 01–04, соответствуют чек-листу аудита; отчёт о находках и техдолге приложен к `history.md`.
